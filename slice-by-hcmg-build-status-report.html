🚀 Recommended Next Steps (In Order)
1

Activate Weekly Emails — Set CRON_SECRET

Go to Vercel Dashboard → hcmg-web → Settings → Environment Variables. Add CRON_SECRET (any string, e.g. hcmg-cron-2025). This activates Monday AM progress emails to all LOs. Takes 2 minutes.

2

Connect ARIVE via Zapier

Follow the step-by-step guide at /goal-engine/admin/arive. Create the Zap in 20 minutes. Use the Live Webhook Tester on that page to confirm data flows before going live. This is what makes the leaderboard update in real time.

3

Create the First Real Goal + Invite All LOs

Go to /goal-engine/admin, create the goal for the upcoming month, and hit Publish. Every active LO profile will receive the announcement email automatically. Make sure all LO profiles have correct emails matching ARIVE.

4

Add "Most Improved" + "Fastest to Commitment" Awards

Small addition to /api/goal-engine/awards/route.ts. "Fastest to Commitment" is a single sort on submitted_at. "Most Improved" compares funded_volume_actual vs. the prior month's leaderboard row.

5

Build Coaching Notes UI for Managers

The DB tables (coaching_notes, coaching_actions) are ready. Need a simple admin page under /goal-engine/admin/coaching where Darius can add a note to any LO, mark action items, and flag follow-ups. Maybe 200 lines of code.

6

Branch-Level Analytics View

Group the Manager Dashboard by branch_id. Add a branch filter and office-level progress bars. The data is already there — it's a UI grouping task.
